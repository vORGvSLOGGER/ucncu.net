# UCNCU.NET 🪙

لعبة اقتصادية تعليمية تنافسية — عالم استثماري متكامل داخل المتصفح.

يبدأ اللاعب كمستثمر مبتدئ برصيد 10,000 UCN ويطوّر ثروته عبر:
**السوق · المزاد · التداول · العقارات · الشركات · البنك · العملات · العملات الرقمية**

## التشغيل

```bash
npm install
npm run dev        # http://localhost:3000
```

```bash
npm run build      # تصدير ثابت إلى out/ — يُنشر على أي استضافة
npm run typecheck  # فحص الأنواع
```

## التقنية

- **Next.js 15** (App Router) + **TypeScript** + **Tailwind CSS v4**
- تصدير ثابت كامل (`output: 'export'`) — لا يحتاج خادمًا
- واجهة عربية RTL بثيم داكن ذهبي/تركوازي وخط Cairo (مستضاف محليًا)
- جميع الرسوم البيانية (شموع، خطوط، Sparklines، Donut، عدادات) SVG مبنية يدويًا — صفر مكتبات خارجية

## آلية اللعبة

- حالة اللعبة كاملة في `localStorage` — تستمر بين الجلسات مع «اللحاق بالغياب»
- محرك أسعار حي (random walk كل 3 ثوانٍ) لكل الأصول
- نظام مستويات وXP ورتب وإنجازات (12 إنجازًا)
- إيجارات دورية، أرباح شركات، أقساط قروض تلقائية، وتقييم ائتماني يتأثر بسلوكك
- مزادات حية ضد لاعبين آليين (bots) يزايدون ضدك
- فتح المزايا بالمستويات مع «وضع الاستكشاف» للمعاينة الكاملة (من البروفايل)

## البنية

```
app/          الصفحات العشر (الرئيسية، البروفايل، السوق، المزاد، التداول،
              العقارات، الشركات، البنك، العملات، العملات الرقمية)
components/   layout (Header, BottomNav, AppShell) + ui (رسوم وعناصر مشتركة)
lib/
 ├─ engine/   reducer, prices, xp, accrual, auction — منطق اللعبة
 ├─ state/    GameContext + localStorage persistence
 ├─ seed.ts   عالم اللعبة: الكتالوجات، البوتات، الإنجازات، الأحداث
 └─ types.ts  نموذج GameState الكامل
```
