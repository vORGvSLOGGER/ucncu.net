# UCNCU.NET 🪙

لعبة اقتصادية تعليمية تنافسية — عالم استثماري متكامل داخل المتصفح.

يبدأ اللاعب كمستثمر مبتدئ برصيد 10,000 UCN ويطوّر ثروته عبر:
**السوق · المزاد · التداول · العقارات · الشركات · البنك · العملات · العملات الرقمية · إكسبلور · الأصدقاء**

## التشغيل

```bash
npm install
npm run dev        # http://localhost:3000
```

```bash
npm run build      # تصدير ثابت إلى out/ — يُنشر على أي استضافة
npm run typecheck  # فحص الأنواع
```

## الأطوار

- **الطور التجريبي** — اقتصاد كامل على جهازك ضد 10 تجار يديرهم الذكاء الاصطناعي. كل ميزة جديدة تنزل هنا أولًا ويقيّمها المجتمع (استبيان «قيّم التحديث» في البروفايل) قبل اعتمادها.
- **طور الحقيقة** (قريبًا) — اقتصاد مشترك بين لاعبين حقيقيين بتسجيل دخول عبر البريد. **الإفلاس فيه نهائي**: من تُشهر إعساره ولا يُنقذ خلال مهلة الخمس ساعات يُحظر بريده من اللعبة للأبد.
- لكل طور تخزين واقتصاد منفصلان تمامًا (`ucncu:demo:v2` / `ucncu:real:v2`) — العدل أولًا.

## تفعيل تسجيل الدخول (Supabase — بريد + OTP)

اللعبة تعمل كاملة كضيف بدون أي إعداد. لتفعيل الدخول بالبريد:

1. أنشئ مشروعًا مجانيًا على [supabase.com](https://supabase.com)
2. من **Settings → API** انسخ `Project URL` و `anon public key`
3. أضفهما كـ **Repository Secrets** في GitHub:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
4. في Supabase: **Authentication → Email Templates → Magic Link** تأكد أن القالب
   يتضمن `{{ .Token }}` ليصل رمز الـ 6 أرقام (وليس رابطًا فقط)
5. ادفع أي commit — سيُبنى الموقع والدخول مفعّل

بدون المفاتيح تظهر صفحة الدخول «غير مفعّل بعد» بأمان تام.

## التقنية

- **Next.js 15** (App Router) + **TypeScript** + **Tailwind CSS v4** + `@supabase/supabase-js`
- تصدير ثابت كامل (`output: 'export'`) — لا يحتاج خادمًا
- واجهة عربية RTL حية: ثيم داكن ذهبي/تركوازي، خط Cairo، تموج بالأزرار، توهج للقسم النشط
- كل التوقيتات بتوقيت السعودية 🇸🇦 (Asia/Riyadh) مع ساعة حية في الهيدر
- جميع الرسوم البيانية SVG مبنية يدويًا — صفر مكتبات رسم خارجية

## آلية اللعبة

- حالة اللعبة كاملة في `localStorage` (v2) — تستمر بين الجلسات مع «اللحاق بالغياب»، وحفظ v1 القديم يُرحَّل تلقائيًا
- محرك أسعار حي (random walk كل 3 ثوانٍ) لكل الأصول
- **تجار أذكياء**: 10 شخصيات باستراتيجيات حقيقية (زخم/قيمة/معاكس/حوت/مضارب/تجميع) يتداولون فعليًا، تتطور ثرواتهم على المتصدرين، وينشرون صفقاتهم في إكسبلور (`PERSONAS_VERSION` للضبط الدوري)
- **سلم ميزات 100 مستوى**: خصومات رسوم وسبريد، فتحات قروض وشركات، مكافأة يومية، حق التبرع (م25) والفزعة (م50) — خطافات فعلية في المحرك
- **الإفلاس والإحسان**: تعثر + أصول لا تغطي الديون ← مهلة 5 ساعات تُعرض حالتك في «إحسان» ليتبرع لك المجتمع أو يفزع لك تاجر كبير — وإلا فالنهاية (في التجريبي: إعادة قسرية)
- **اجتماعي**: أصدقاء وشات بردود شخصية، بيع مباشر بمساومة، شراكات تضخ رأسمالًا بشركاتك
- **المزاد ≠ السوق**: طبقات ندرة (نادر/أسطوري/خارق ✦) وإعادة عرض مقتنياتك بمزادك الخاص (عمولة 5%)
- سجل نشاط مصنّف في الرئيسية بدل النوافذ المنبثقة — والجرس للاجتماعي والجوهري فقط
- **تتوريال تفاعلي** بسبوت لايت عبر الصفحات يشرح المفاهيم الاستثمارية بمكافآت XP
- شريط سفلي قابل لإعادة الترتيب على الجوال + أقفال ظاهرة للأقسام الأعلى من مستواك
